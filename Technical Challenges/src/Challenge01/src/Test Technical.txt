# TESTE TÉCNICO #01 — Java + POO

**Nível estimado:** iniciante avançando → intermediário inicial  
**Objetivo:** estabelecer sua linha de base prática.

Este primeiro teste é propositalmente calibrado para o que você **já estudou**. Não vou cobrar Spring, banco de dados, Collections avançadas ou conceitos que ainda não fazem parte da sua formação atual.

### Cenário:

Você foi contratado para desenvolver a parte inicial de um pequeno **sistema de estoque**.

O sistema precisa representar produtos armazenados em estoque.

Cada produto deve possuir:

- "nome"
- "preço"
- "quantidade"

O sistema deverá permitir:

1. Cadastrar um produto.
2. Exibir os dados do produto.
3. Adicionar unidades ao estoque.
4. Remover unidades do estoque.
5. Calcular o valor total daquele produto em estoque.

### Regras de negócio

**Cadastro**
- O nome não pode ser vazio.
- O preço não pode ser menor que zero.
- A quantidade inicial não pode ser menor que zero.

**Entrada de estoque**
- A quantidade adicionada deve ser maior que zero.

**Saída de estoque**
- A quantidade removida deve ser maior que zero.
- Não pode ser retirada uma quantidade maior do que existe no estoque.

**Valor total**

```text
valorTotal = preco × quantidade
```

### Requisitos técnicos

Você deverá criar pelo menos:

```text
Main
Produto
```

A classe `Produto` deve ser responsável pelos **dados e comportamentos relacionados ao produto**.

Utilize os conceitos de POO que você já estudou, especialmente:

- classe;
- objeto;
- atributos;
- encapsulamento;
- `private`;
- getters/setters quando fizer sentido;
- métodos;
- parâmetros;
- retorno;
- construtor.

### Exemplo de comportamento esperado

Uma execução poderia resultar em algo semelhante a:

```text
Produto: Teclado
Preço: R$ 150.00
Quantidade: 10
Valor total em estoque: R$ 1500.00

Adicionando 5 unidades...

Quantidade atual: 15

Removendo 3 unidades...

Quantidade atual: 12
Valor total em estoque: R$ 1800.00
```

**Isso é apenas uma demonstração do comportamento. Não copie essa estrutura cegamente.**
